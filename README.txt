CINEMORA — Premium Movie Website
=================================

Files:
- index.html       Main cinematic homepage
- play-page.html   Dynamic movie detail + trailer modal page
- style.css        Premium responsive styling and animations
- script.js        Search, filters, carousel controls, hero slider, favourites, tilt, reveal animations

Assets:
The supplied images are copied with clean filenames. The supplied MP4 is included as trailer-demo.mp4.

Open index.html in a browser.
For the detail page, links use:
play-page.html?movie=fighter
play-page.html?movie=jawan
play-page.html?movie=amazon
...and other movie IDs in script.js.

Notes:
- This is a front-end demo. Replace the supplied demo trailer with media you are licensed to distribute.
- Google Fonts and Boxicons load from CDNs.
